# @xaravel/filesystem

Xaravel's port of Laravel's illuminate/filesystem component. Part of Xaravel, a TypeScript port of Laravel.

It ports `illuminate/filesystem` from Laravel v13.37.0.

Xaravel is an independent open-source project. It is not affiliated with, sponsored by or endorsed by Laravel Holdings Inc.
