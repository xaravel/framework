# ESC-14.1-1: the runtime's PHP-array helpers are internal, so Collection cannot read or build PHP arrays without copying them

Collection is a PHP array with methods. The runtime already reads the three JS forms of a PHP array (list, plain object, `PhpArray`), normalises keys and builds the right form back, but none of it is exported. Option 1 exports those helpers and `get_debug_type` from `@xaravel/runtime/php`. Option 2 copies them into `packages/collections`. Every Test ID of the Story except testDump (which is `blocked-by:support`, VarDumper) needs one or the other, so the Story's build stops here. The other three Escalations name the Test IDs that also need something more.
