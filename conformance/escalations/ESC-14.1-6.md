# ESC-14.1-6: the Collections core needs PHP functions and the `(array)` cast, which the runtime does not export

Laravel's Collection calls PHP's array functions (`is_scalar`, `iterator_to_array`, `array_combine`, `array_filter`, `array_unique`, `in_array`, `range`) and PHP's `(array)` cast from its constructor, `toArray` and `unique`. `@xaravel/runtime/php` exports none of them, and the rules say nothing outside the runtime re-implements PHP semantics. Option 1 adds them to the runtime, in the same item as ESC-14.1-5. Option 2 writes private copies in `packages/collections`. Every constructor needs `is_scalar`, so the Story's build stops here. Only the four `unwrap` rows with an array or a scalar construct nothing; they wait with the Story.
