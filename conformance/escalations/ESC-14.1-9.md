# ESC-14.1-9: the Collections core still needs PHP type tests and functions the runtime does not export

After ESC-14.1-1..8 and the two runtime items landed, a third trace of every Test ID through Upstream found the rest of what the core calls and the runtime lacks. Every constructor tests `instanceof UnitEnum`, LazyCollection tests `instanceof Closure` and `instanceof Generator` and calls `is_callable`, `ensure` tests `instanceof` by name, and `toArray`, `values`, `count`, `range` and `data_get` need `array_map`, `array_keys`, `array_values`, `count`, `abs`, `explode` and the `array_key_*` functions. None of these is exported. Option 1 adds them to the runtime in one more item, so Collections, Support and Reflector share one implementation. Option 2 writes private copies in `packages/collections`. Every constructor needs the enum test, so the Story's build stops here; testGetArrayableItems waits on ESC-14.1-10 too.
