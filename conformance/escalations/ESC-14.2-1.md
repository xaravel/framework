# ESC-14.2-1: Story 14.2's methods need PHP array functions and builtins the runtime does not export

Story 14.2 ports `first`, `last`, `contains`, `has`, `search`, `before`, `after`, `slice`, `take`, `pop`, `shift`, `unshift`, `splice`, `only`, `pluck`, `random`, `pull` and `value`, with their Arr and helper counterparts. Upstream builds them on PHP 8.4 and 8.5 array functions (`array_any`, `array_all`, `array_find_key`, `array_first`, `array_last`), the by-reference array functions, `array_slice`, `array_search`, `array_flip`, `min`, `str_contains`, `property_exists`, `method_exists`, `Random\Randomizer` and PHP 8.6's `SortDirection`. The runtime exports none of them, nor PHP's `===` for arrays, nor the PHP names `is_numeric` and `is_float`. Option 1 adds them to the runtime in one item, under the standing rule for runtime builtins. Option 2 writes private copies in `packages/collections`. `Arr::first` and `contains` sit under most of the Story's Test IDs, so the build waits for this ruling. The 22 Test IDs it does not hold are built in the same pass after the ruling.
