## Intent

**Problem:** FR-8 and AD-26 require a `PORTING.md` rulebook before Phase 1 starts, and CI must check it. No such file exists. No rule says how a PHP expression in an Upstream test input or Blade template becomes TypeScript. The DIV-12 pair list, the frame-slot list, the `APP_KEY` forms and the `Promise.all` allow-list each point to `PORTING.md`, and it does not exist yet.

**Approach:**
- Write the root `PORTING.md` from the spine and the PRD.
- Implement the mechanical expression rule as a syntax-directed translator, `tools/porting/translate.ts`. Prove it on a committed 20-entry fixture of real Upstream test inputs.
- Add a fail-closed gate, `bun run porting:check`, which Story 8.8 can reuse as `checkPorting(root)`. It checks the required sections and every AD-26 row (read from the spine) marked `decided`, and that the generated DIV-12 region matches `div12-pairs.jsonl`. It also checks that every fixture entry translates to its committed TS. `porting:generate` rewrites the DIV-12 region. CI runs the check in the required `check` job.

  1. `property.static !== method.static` → `no collision (static and instance sides)`.

The rename comes from a constant map in the tool: `fillable` → `setFillable`, `touches` → `isTouching` (DIV-12.4). A configuration-list name with no map entry is a violation, `no AD-7 rename for <name>`.
  3. `option-pair` → `option(this, name)`.
  4. Anything else → `method keeps the name; state behind Upstream's getters`.
  The region ends with a count line, `<r> pairs in <g> groups.`.

## Design Notes

**Rule table** (expr mode; Blade mode differs only where noted). It is syntax-directed: no type information is used. Type-dependent rewrites are adaptations under a DIV clause.

| PHP | TS |
| --- | --- |
| `$x`, `$this` | `x`, `this`. Blade mode keeps `$x` (AD-11). |
| `\A\B\C`, `C` (class name) | `C` (imports are not part of the rule) |
| `C::class` | `C` |
| `->`, `?->`, `::` (calls, properties, constants, `C::$p`) | `.`, `?.`, `.` |
| `f(...)`, `$o->m(...)` (first-class callable) | `f`, `o.m.bind(o)` |
| named arguments `f(1, b: 2, c: 3)` | `f(1, { b: 2, c: 3 })` (trailing named arguments become one object, AD-26) |
| bare function or constant name | kept verbatim (helpers come from `@xaravel/support`, PHP builtins and constants from `@xaravel/runtime/php`) |
| `true`/`FALSE`/`Null` | lower case |
| numbers; `017`/`0o17` | as written; `0o17` |
| integral float literal `1.0` | `float(1)` (DIV-9 float marker) |
| `'s'`, `"s\t$v {$o->p}"` | a JS single-quoted string; interpolation becomes `'s\t' + toPhpString(v) + ' ' + toPhpString(o.p)` |
| `a . b` | `toPhpString(a) + toPhpString(b)`; a string-literal operand is not wrapped |
| list `[1, 2]`, `array(1, 2)`, spread `...$a` | `[1, 2]`, `...a` |
| every key a non-integer-like string literal | `{ a: 1, 'b-c': 2 }` |
| any other keyed array | `new PhpArray([[k, v], …])`; an implicit key gets the next literal integer index, and a non-literal key before an implicit one is untranslatable |
| `$a[k]` | `a[k]` (ArrayAccess receivers adapt to `.get(k)` under DIV-12) |
| `==`, `!=`/`<>`, `<=>` | `looseEquals(a, b)`, `!looseEquals(a, b)`, `spaceship(a, b)` |
| `===`, `!==`, `< > <= >=`, arithmetic, bitwise, `??`, `instanceof` | unchanged |
| `!`, `&&`, `||`, `c ? a : b` | operands and conditions wrapped `toBool(…)` unless boolean-shaped (comparison, `!`, `&&`/`||`, `instanceof`, `isset`, `empty`, a boolean literal) |
| `a ?: b` | `toBool(a) ? a : b` when `a` is a variable or literal; otherwise untranslatable |
| `(int)`, `(float)`/`(double)`, `(string)`, `(bool)` | `toInt`, `toFloat`, `toPhpString`, `toBool` |
| `isset(e1, e2)`, `empty(e)` | `(e1 ?? null) !== null && …`, `!toBool(e ?? null)` |
| `fn (T $a) => e`, `function ($a) use ($b) { return e; }` | `(a) => e` (types dropped, `use` dropped) |
| `new C(args)`, `$a = e` | `new C(args)`, `a = e` |
| `__DIR__` | `import.meta.dir` |

**Untranslatable** (throws `UntranslatableExpression`): `match`, `throw`, `(array)`/`(object)`/`(unset)`, `static::`/`self::`/`parent::`, heredoc or nowdoc with interpolation, `@`, `print`/`echo`/`exit`, `list()`/destructuring, `and`/`or`/`xor`, a `function` closure with a body other than one `return`, `new class`, the other magic constants, `` ` ``, and statements.

**Blade templates.** `translateBladeTemplate` translates expressions inside `{{ }}`, `{{{ }}}`, `{!! !!}` and directive parentheses `@name(...)`. `@foreach`/`@forelse` translate the iterable and keep `as $k => $v`. Everything else is copied byte for byte, and `@php … @endphp` is untranslatable.

**Example.** `\Illuminate\Support\Str::words("\t\t\t")` → `Str.words('\t\t\t')`. Blade: `Hello {{ $user->name }}` → `Hello {{ $user.name }}`.
