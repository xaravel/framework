## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| Round trip | factory-built `object([...])->title()->description()` | `serialize(fromArray(serialize(t))) === serialize(t)`; `fromArray(...) == t` | none |
| Nullable forms | `type: ['string','null']`, `anyOf`/`oneOf` with one `null` branch | single Type, `nullable()` set; sibling keys merged | conflicting sibling → `Conflicting [type] between a "anyOf" branch and its sibling keys.` |
| Unions | `type: ['number','string','number',…]` | `UnionType` deduped in order; nullable when `null` present | `Unsupported JSON Schema type [123] in a multi-type union.`; type-specific keywords → `Type-specific keywords [items] are not supported…` |
| `$ref` | `#/$defs/X`, `#/definitions/X`, `#`, sibling keys | resolved, siblings override, cached per ref | circular → `Circular JSON Schema $ref [#] detected.`; remote; unresolvable; non-schema target |
| Inference | no `type`, with `properties` / `items` / homogeneous `enum` / string or numeric keywords | object / array / enum's scalar / string / number | none → `Unable to determine the JSON Schema type for the given schema.` |
| Bad constraints | `minimum: 'oops'`; integer `minimum: 1.9`; tuple `items`; `properties.meta: true`; `default: null` | — | Upstream's message for each |

## Design Notes

`$this->assertEquals($type, $rebuilt)` compares two Type objects through the props protocol 16.1 built (`[PHP_PROPS]`), so the rebuilt Type must hold the same state, including `requiredProperty` on required children and a float-marked `multipleOf(0.5)`.

Example of the default setter (shape only):

```ts
// internal: PHP's Closure::call into the Type's scope, for Deserializer::applyCommon.
export const ASSIGN_DEFAULT: unique symbol = Symbol("xaravel.json-schema.assignDefault");
// Type.ts
[ASSIGN_DEFAULT](value: unknown): void { this.defaultProperty = valueCopy(value); }
```
