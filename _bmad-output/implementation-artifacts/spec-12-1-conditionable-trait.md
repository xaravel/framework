## Intent

**Problem:** `@xaravel/conditionable` is an empty scaffold (`src/index.ts` is `export {};`). Laravel's `Illuminate\Support\Traits\Conditionable` (`when`, `unless`) and `Illuminate\Support\HigherOrderWhenProxy` have no port, so all 8 Test IDs are `not-ported-yet`, and every later package that mixes Conditionable in has nothing to import.

**Approach:** Port the trait as a runtime trait class (`class X extends mixin(Base, Conditionable)`) and the proxy as a plain class, one-for-one from Upstream, with Upstream's explicit `__get(key)` / `__call(method, parameters)` methods plus DIV-12.12's generated delegating members, and no JS Proxy. `when` / `unless` are AD-6 dual helpers typed by their callbacks' own return types (F-9; decisions/MAINT-2026-10-25-story-12-1-replan.md), and a thenable condition throws (DIV-1.6). They take only the positional form (DIV-12.13). Port all 6 `SupportConditionableTest` tests, port the 2 `ConditionableTest` tests as `blocked-by:database` (ESC-12.1-2), and add XT-conditionable-1..3. Re-plan of the first attempt: start from `12-1-attempt-1.patch`, apply the rulings ESC-12.1-1..3 and the Review Triage Log's `[patch]` rows, then delete the patch file.

## Boundaries & Constraints

**Always:**
- Edit only `packages/conditionable/**` and the 8 lines in `conformance/expectations/conditionable/**`. Orchestrator bookkeeping (this spec, sprint status, the `stories/12.1.md` status, deleting `12-1-attempt-1.patch`) is the only other change. `conformance/api-surface/exceptions.jsonl` already exempts `when` / `unless` (DIV-12.13), and `BlockedByComponentError` is already in `@xaravel/runtime` (action item `epic-12-item-1-blocked-by-component-error`).
- Files sit at the Upstream file path: `src/Traits/Conditionable.ts` (FQCN `Illuminate\Support\Traits\Conditionable`) and `src/HigherOrderWhenProxy.ts` (FQCN `Illuminate\Support\HigherOrderWhenProxy`). Each file ends with `registerClass('<FQCN>', X)`. `src/index.ts` has named exports only.
- Port Upstream's logic exactly:
  - A `value` that is a PHP Closure (a function that is not a class: not `class` source, no FQCN brand, not a native constructor) is called with `this` and replaced by its result.
  - Argument count is `arguments.length`, standing in for `func_num_args()`. With 0 arguments, `when` returns `new HigherOrderWhenProxy(this)`, and `unless` returns that proxy after `.negateConditionOnCapture()`. With 1 argument, `when` returns the proxy with `.condition(value)`, and `unless` returns it with `.condition(!toBool(value))`.
  - Otherwise, if PHP-truthy (`toBool`; `unless` negates), the result is `callback(this, value) ?? this`. Else, if `default` is given, it is `default(this, value) ?? this`. Else it is `this`.
  - `?callable` at entry, as PHP checks it on every branch: a `callback` / `default` that is neither `null` (`undefined` read as `null`) nor a function throws PHP's `TypeError` `<class>::when(): Argument #2 ($callback) must be of type ?callable, <type> given` (`#3 ($default)` for the default), `<class>` being `fqcn(this)` (`class@anonymous` when unregistered).
  - The proxy's `condition`, `negateConditionOnCapture`, `__get(key)` and `__call(method, parameters)` follow Upstream line for line. A captured condition is negated with PHP `!` (`!toBool(x)`). `__get` reads `target[key]` when the target has `key`, else calls the target's own `__get(key)` when it has one, else gives `null` (PHP's undefined-property read). `__call` calls `target[method](...parameters)` when it is a function, else the target's own `__call(method, parameters)` when it has one, else throws PHP's `Error` `Call to undefined method <class>::<method>()`. An `undefined` result reads as `null` (AD-9).
- Generated delegating members (DIV-12.12, ESC-12.1-1): at construction the proxy defines, as non-enumerable own members, one method for each function-valued data property on the target's prototype chain below `Object.prototype` (routing through `__call(name, args)`), and one getter for each own string-keyed property of the target (routing through `__get(name)`). `constructor`, `then` and every name the proxy declares (its prototype chain's members) are excluded. Its state (`#target`, `#condition`, `#hasCondition`, `#negateConditionOnCapture`) and helpers are `#private`, so Upstream's state names stay and no target name collides with them; DIV-12.2's renamed state is no longer needed. The types expose the members: `when()` / `unless()` with no argument return `CapturingWhenProxy<this>`, whose members return a `ConditionedWhenProxy<this>`; with one argument they return `ConditionedWhenProxy<this>`, whose method members return `ReturnType | T` and property members `T[K] | T`.
- Dual helper (AD-6, F-9, the replan ruling): `when` / `unless` take no `@asyncRoot` tag and declare no Promise or thenable type. Their return type is the callbacks' own types, `Exclude<R | D, null | undefined | void> | this`; an async callback's own Promise is returned as is (`result ?? this`). `async-surface.json` has no line for them.
- A Promise is never a condition (DIV-1.6): a thenable `value` (an object or function with a callable `then`), a thenable returned by the `value` closure, and a thenable captured by the proxy's `__call` / `__get` each throw a JS `TypeError` saying to await it before the call. The types reject a Promise condition with `NotPromise<V>`. A thenable returned by a callback is an ordinary result.
- Positional form only (DIV-12.13, ESC-12.1-3): a lone object argument is always the condition. `default` is a reserved word, so the positional parameter is `defaultValue`.
- `null` is the only absent value, so never return `undefined` (AD-9).
- Port the tests by `PORTING.md`. PHP closures that do not use `$this` become arrow functions. `ConditionableLogger` is a local fixture registered with `registerTestClass`; its `$toggle` property becomes `toggleProperty` beside the `toggle()` method, and each Upstream read of `->toggle` (through the proxy) becomes `.toggleProperty`, marked `// adapted:DIV-12.12`. `ConditionableTest`'s `setUp` throws `new BlockedByComponentError("database")` before building the Capsule, and its two bodies are ported as Upstream's, with a local `TestConditionableModel` left out (it needs `Model`).
- Every public member has a docblock. Docs go in `packages/conditionable/docs/conditionable.md`, linked from `README.md`.

**Never:**
- No JS `Proxy` (AD-7, AD-26). No member generated after construction.
- Never change `@xaravel/runtime`, `@xaravel/contracts`, `tools/`, `conformance/api-surface/` or any other package, and never define a local `BlockedByComponentError`, `Builder` or `Model` stand-in.
- No assertion removed or weakened, and no `adapted:` marker other than `DIV-12.12` on the `toggleProperty` reads.
- No module variables or static state; no options form.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| Truthy value | `x.when(2, cb, def)` | `cb(x, 2) ?? x`; `def` not called | none |
| Closure value | `x.when(s => s.has('init'), cb)` | closure's result decides; `cb` gets it as `value` | none |
| Falsy, default | `x.when(null, cb, def)` / `x.when("0", cb, def)` | `def(x, value) ?? x` | none |
| Falsy, no default | `x.when(false, cb)` | `x` | none |
| No arguments | `x.when()` | a `HigherOrderWhenProxy` with no condition; `unless()` also negates on capture | none |
| One argument | `x.when(false)` / `x.unless(true)` | proxy with condition `false`; `__call('log', ['a'])` returns `x` without calling `log` | none |
| Capture | `x.when().__call('has', ['init'])` then `.__call('log', ['3'])` | condition is `has`'s result; `log` runs only if truthy | none |
| Higher-order call | `x.when(true).log('one')` / `x.when().has('init').log('three')` | the generated member routes through `__call`; same results as Upstream | none |
| Higher-order property | `x.when().toggleProperty.log('five')` | the getter routes through `__get`, capturing `false` | none |
| Missing method | `x.when(true).__call('nope', [])` | target's `__call` if any, else PHP `Error` `Call to undefined method <class>::nope()` | throws |
| Missing property | `x.when(true).__get('nope')` | target's `__get` if any, else `null` | none |
| Async callback | `x.when(true, async s => 1)` | the callback's own Promise, resolving `1` | rejection propagates |
| Thenable condition | `x.when(Promise.resolve(true), cb)`, `x.when(async s => true, cb)`, `x.when().__call('asyncMethod', [])` | JS `TypeError` (await it first) | throws |
| Builder-like thenable result | callback returns an object with `then` | returned as is, sync | none |
| Not callable | `x.when(true, 5)` / `x.when(false, null, 'x')` | PHP `TypeError` `…::when(): Argument #2 ($callback) must be of type ?callable, int given` | throws |
| Options-shaped value | `x.when({ value: false, callback: cb })` | the object is a truthy condition: `cb(x, obj)` runs | none |

## Design Notes

**A callback's result is never inspected.** Builders and Relations are thenable (AD-6), and `$query->when($x, fn ($q) => $q->where(...))` is Laravel's commonest use. The dual helper returns whatever the callback returns (`?? this`), so a Builder stays a Builder and an async callback's own Promise is returned. Only the condition is checked for a thenable (DIV-1.6), since PHP truthiness would always take the `callback` branch.

**Entry `?callable` type name.** `@xaravel/runtime`'s `phpTypeName` is internal (not exported), and this Story may not change the runtime. The message needs only PHP's names for the non-callable values a caller can pass (`true`/`false`, `int`, `float`, `string`, `array`, a class name), so a small local mapping builds it; the docs record it.

**Proxy member typing.** The members are installed at runtime, so the class type cannot list them. `when` / `unless` return intersection types over `keyof T` (minus the proxy's own names and `then`) that model Upstream's two states: before capture each member yields a conditioned proxy, after it a method yields its result or the target.
