## Design Notes

- **Why hold whole members.** A member whose Collection side would work but whose LazyCollection side needs a missing builtin (`flip`: `is_int`) is held whole: a partial member is forbidden, and its Test IDs are paired anyway.
- **`implode`'s `Stringable`.** `Collection.php`'s `use` lines (5-14) do not import PHP's `\Stringable`, so `Stringable` is `Illuminate\Support\Stringable`. `is_a` through the Class Registry gives `false` until Support registers it, as PHP would for an object that is no such instance. No stub.
- **Arr members ported early.** `flatten`, `dot`, `undot`, `set`, `crossJoin` are reached by this Story's members; as 14.3 did for `concat` / `keyBy`, they are ported in full here and tested by Story 14.6's Test IDs.
