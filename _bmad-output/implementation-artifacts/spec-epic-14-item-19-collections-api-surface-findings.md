## Intent

**Problem:** With `tools/api-surface` now following `extends`, `mixin(...)` members and aliases (#526), `bun run api-surface:gate collections` reports 144 unexplained findings (ESC-14.8-1 part 2). Some are genuine differences from Upstream v13.37.0 inside `packages/collections`: wrong parameter names, nullable parameters and returns where Upstream is typed non-null, missing AD-26 options overloads, missing parents, missing members and missing helper functions. Story 14.8 cannot close until they are fixed.

**Approach:** Fix every genuine finding in `packages/collections` (groups G1-G13 below) without changing behaviour that Ported Tests already pin, and port the six missing Upstream helpers with Xaravel Tests whose expected values come from a committed PHP 8.5.11 probe. List every finding that is not genuine, with its evidence, in the PR body for the monitor: explained by existing text (E), needing another component (O), a gate-tool limitation (T), or needing a ruling (U).

## Boundaries & Constraints

**Always:** Scope is `packages/collections/**` plus this item's records under `_bmad-output/implementation-artifacts/`. Keep Laravel's names (AD-3); `null` is the only absent value (AD-9); sync only, and `when` is an AD-6.5 dual helper like `value`. The by-reference helpers take a `Ref` (DIV-9.2), as `Arr.set` does. Every new options overload reads its options object at runtime through `isOptionsObject` (never a cast that ignores it). New Xaravel Tests start at XT-collections-17 and use only `xaravelTest` / `@xaravel/assert`. Test edits in `packages/collections/tests/**` are type-only (`as never` casts on deliberate wrong-type calls) and change no assertion or expected value.

**Never:** Edit `conformance/api-surface/exceptions.jsonl` / `additions.jsonl`, any `conformance/expectations/**` line, `tools/**`, another package, a DIV, the item's `action`/`owner`/`epic`. Never add a camelCase alias export (`dataGet`) or any duplicate forwarding method to satisfy the analysis. Never `@ts-nocheck` or `@ts-ignore` a test. Never remove the `...moreKeys` / `...moreItems` rest parameters or `Enumerable.reduceWithKeys` (U1, U2: they need a ruling). Never port `dd`/`dump`, `toResourceCollection`, `TransformsToResourceCollection`, `takeUntilTimeout`, `throttle` or `withHeartbeat` (O).
