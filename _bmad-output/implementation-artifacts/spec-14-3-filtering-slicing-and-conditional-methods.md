## Intent

**Problem:** The 148 Test IDs of Story 14.3 (SCT `testFilter`, `testReject*`, `testWhere*`, `testBetween`, `testUnique*`, `testDuplicates*`, `testSkip*`, `testTake*`, `testSlice*`, `testEvery`, `testPartition*`, `testHigherOrder*`, `testHigh*`, `testWhen*`, `testUnless*`; 74 tests × the `collectionClassProvider` rows `#0` Collection / `#1` LazyCollection) are `not-ported-yet`, and XT-collections-6/7 do not exist. Collection and LazyCollection lack the filtering, slicing and conditional members, the async companions, and the `NotPromise` typing that rejects async callbacks to sync members (AD-6).

**Approach:** Port the missing members line for line over `@xaravel/runtime` on both classes, add the six async companions the AC names, type sync callbacks so `tsc` and oxlint both reject an async callback, and port the tests in Upstream order. Planning found seven PHP builtins the runtime does not export; they hold 20 Test IDs, raised as ESC-14.3-1 (contract, under the runtime-builtins standing rule). The other 128 Test IDs and XT-collections-6/7 are built now, and the Story then halts `blocked` on ESC-14.3-1, as 14.2 did on ESC-14.2-1.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |

| filter keeps keys | `collect([1,2,3,4])->filter(fn($v) => $v % 2 === 0)` | keys `[1, 3]`; `toJson()` `{"1":2,"3":4}`; `values()` `[2,4]` / `"[2,4]"` (XT-collections-6, Oracle) | — |
| negative take | `take(-2)` on 5 items | last two, keys kept (testTakeLast) | — |

| companions in order | `filterAsync` with callbacks that await | callbacks start one after another in key order, never overlapping; result keeps keys | a rejected callback rejects the companion's Promise |

## Design Notes

- **Why ESC-14.3-1 holds whole tests.** `TestSupportCollectionHigherOrderItem::uppercase()` calls `strtoupper`, so the fixture cannot be ported without it, and every test that constructs it waits (Sole, TakeUntilCanBeProxied, TakeWhileCanBeProxied, GroupBy, Map, MapFromArrays). A fixture missing that method would be partial.
- **SyncCallback** (planning experiment on oxlint 1.88 / tsc 7.0.2, temp dir): `filter<R>(cb: ((v, k) => NotPromise<R>) & ((v, k) => void))` — `c.filter(async () => true)` gives `TS2322` and `no-misused-promises`; `c.filter((v) => v > 1)` and `(v, k) => v > k` compile clean with contextual types. No lint rule or `.oxlintrc.json` change is needed.
- **Companions are not dual helpers.** They always return a Promise and exist because DIV-1 allows their callback to be async, so `@asyncRoot callback` is true under F-9 — the opposite of Story 12.1's `when` / `unless`. `eachAsync` / `mapAsync` belong to Story 14.5 (epics.md:3676).
