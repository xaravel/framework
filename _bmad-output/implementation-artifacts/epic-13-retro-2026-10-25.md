### Diff-scope review (adversarial, edge-case, verification-gap lenses)

A sub-agent reviewed #435, #442 and #443 against Upstream `Illuminate\Support\Reflector` and `Traits\ReflectsClosures` (`conformance/upstream/framework/src/Illuminate/Reflection/`). It weighted the boundary between the runtime reflection the items built and the Reflector the Story built on it, and reproduced each behaviour claim with a read-only `bun -e` probe. No repository file changed. The orchestrator re-checked L1, L2 and L3 against the cited lines. Checked and sound: the `isCallable` array rules and the `syntaxOnly` early return; `getTypeName`'s `self` / `parent` handling; the `array_filter` port; a variadic giving null; the order of the `first*` exception messages; `closureReturnTypes`' filter and the DNF `Error`; no `undefined` leaks; `registerClass` ends every new class file; every changed Ported line carries an `adapted:DIV-*` marker and no assertion was removed or weakened; the six skips are the ones `MAINT-2026-10-25-story-13-1.md` and ESC-13.1-10 name; `ReflectionEnum`'s `isBacked()` guard; class-string `assertInstanceOf` through `Symbol.for('xaravel.class.lookup')`.

- **L1. A second token under an existing FQCN makes `isParameterSubclassOf` answer for the first one.** `registerContractToken` keeps the first token recorded under a name and ignores later ones (`packages/runtime/src/registry/registry.ts:233-241`), with no test-frame overlay as `registerTestClass` has. `Reflector.isParameterSubclassOf` turns the parameter's token into a name and resolves it again (`packages/reflection/src/Reflector.ts:251-256`), so it compares the first token's parents. Probe: `contract("Q\\I")`, then `I2 = contract("Q\\I", {}, [P2])` and `inject({ x: I2 })`: `isParameterSubclassOf(p, P2)` is `false`, while `new ReflectionClass(I2).isSubclassOf(P2)` is `true`. It is reachable now: `packages/contracts/tests/xaravel/contract.test.ts:20` declares a test-local `Illuminate\Contracts\Support\Arrayable`, and `bun test` runs every file in one process. ESC-13.1-7 ruled "first one wins" for the lookup, not for a parameter that already holds its token. *Fix now* (action item 5): reflect the parameter's own type rather than its name.
- **L2. A closure's `self` / `parent` never resolves.** `ReflectionFunction.getParameters` builds parameters with no declaring class (`packages/runtime/src/php/ReflectionFunction.ts:35`), so `Reflector.getParameterClassName` returns `"self"` / `"parent"` as written (`packages/reflection/docs/reflection.md:40`). PHP's `ReflectionParameter::getDeclaringClass()` gives a closure's scope class, so `function (self $e) {}` inside `Foo` gives `Foo`. DIV-3.2 says only that the markers "resolve against the declaring class" (`decisions/DIV-3.md:35`); the docs record the gap, but no DIV clause does. Per LESSONS (epic 11, epic 12) it is fixed or recorded through an Escalation. *Fix now* through the Maintainer (action item 6).
- **L3. A `'Class::method'` string naming an instance method is callable.** `isCallable` sends a string to the array rules (`Reflector.ts:308-314`), which accept instance methods, and XT-reflection-1 pins `isCallable("…\\Listener::handle")` as `true` (`packages/reflection/tests/xaravel/reflection.test.ts:334`). Upstream calls PHP 8's native `is_callable` for a non-array, which gives `false` there. DIV-9.14 lists "two edges" (`decisions/DIV-9.md:46`) and not this one, though its "a `'Class::method'` string the rules above resolve" can be read to include it. Which reading the Maintainer meant decides whether this is a fix or a recorded edge. *Fix now* through the Maintainer (action item 6).
- **L4. An unregistered constructor is callable on its own but not in an array.** `isCallable(Unregistered)` gives `true` (`Reflector.ts:292-293`) though calling it throws `TypeError: Class constructor cannot be invoked without 'new'`, while `[Unregistered, 'f']` gives `false` through the local `classExists` (`:62-72`, `:121`, tested at `reflection.test.ts:348-349`). DIV-9.14 says "a class is a constructor", and the docs say "a registered class" (`reflection.md:46-47`). AD-10 registers every framework class, so it is rare. *Fix now* within action item 5: pin the bare case in an XT test and make the docs say which classes count.
- **L5. A parameter typed with an unregistered class throws instead of giving its name.** `typeOfSpec` calls `fqcn(spec)` (`packages/runtime/src/php/reflectionTypes.ts:30-31`), so `getParameterClassName`, `getParameterClassNames` and `isParameterSubclassOf` throw `TypeError: fqcn(): the class is not registered…` where PHP returns the hinted name. `packages/runtime/docs/reflection.md:32` records it; the reflection docs and tests do not. *Fix now* within action item 5 (docs and an XT pin); the Container Story that maps it to `BindingResolutionException` is Epic 17's to name.
- **L6. `static` is accepted as a parameter Spec** (`reflectionTypes.ts:27-28`): `inject({ s: static })` gives `"static"` from `getParameterClassName`, where PHP rejects `static` as a parameter type at compile time and DIV-3.4 allows it only for returns. *Accept*: no framework code declares it.
- **L7. PHP predicates are copied again.** `Reflector.ts:26-44` re-implements `is_object` / `is_array` over DIV-9.2's plain-object rule, also kept in `packages/assert/src/comparison/PhpComparison.ts:125` and Mockery's `Double.ts`; `Reflector.ts:47-57` duplicates `registeredName` (`packages/runtime/src/php/reflectionTargets.ts:12-21`); and `classExists` (`Reflector.ts:62-72`) sits beside the runtime's `interfaceExists` / `enumExists` (`classExistence.ts`). LESSONS (epic 4–10) asks for one implementation. *Defer* to the first Story that needs `class_exists` or `is_array` outside Reflection (Container, Epic 17), which should take them from the runtime; recorded here so that Story's plan sees it.
