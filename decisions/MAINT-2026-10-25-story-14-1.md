# Maintainer ruling: Story 14.1, Collections' runtime pieces

The Maintainer gave this ruling on 2026-10-25 in the Maintainer's session. It approves the orchestrator's recommended option on each of Story 14.1's four Escalations (#450), with the monitor's agreement.

| Escalation | Option | What it adds |
|---|---|---|
| ESC-14.1-1 | 1 | `@xaravel/runtime/php` exports `arrayEntries`, `arrayFromEntries`, `normalizeKey`, `gettype` / `get_debug_type` |
| ESC-14.1-2 | 1 | The runtime adds `Traversable`, `Iterator`, `IteratorAggregate`, `JsonSerializable`, `Stringable`, `Throwable` (contract tokens), `ArrayIterator`, `ArrayObject`, `CachingIterator` and an iterable PHP `WeakMap` |
| ESC-14.1-3 | 1 | DIV-12.16: higher-order collection messages are written as `__get` / `__call` |
| ESC-14.1-4 | 1 | DIV-12.17: index writes, `isset` and `unset` become `offsetSet` / `offsetExists` / `offsetUnset` |

## The route

1. **Infrastructure first.** Action item `epic-14-item-1-runtime-php-types` builds the runtime half of ESC-14.1-1 and ESC-14.1-2, as one Maintainer-approved Infrastructure change.
   - **Scope:** `packages/runtime` and `packages/contracts`. `packages/contracts` is included in case a token needs `contract(...)` or the token table's recording export (ESC-13.1-7).
   - **Tests:** XT-runtime cases for each export and type.
   - **Limits:** no other runtime behaviour changes, and the runtime does not import contracts (AD-2).
   - The loop takes action items before Stories, so this lands first.
2. **Then Story 14.1.** It resumes and ports its Test IDs under these rulings and DIV-12.16 / DIV-12.17. testDump stays `blocked-by:support` (VarDumper). No assertion is removed or weakened.
