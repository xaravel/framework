## Amendment 2026-10-27: locale scope narrowed

The Maintainer narrowed ESC-14.5-1's locale scope to `C` and `POSIX`. `setlocale` returns `false` for any other locale until a later item reproduces one, checked against the Oracle in CI. The loop's host has no Docker, so it cannot run the Linux Oracle. Item `epic-14-item-10-runtime-chunk-sort-arith-callables` needs no Oracle run, and it leaves epic 14's `waiting_on_maintainer`. The same day the Maintainer switched the Codex loop to `--approve-for-me` (`tools/orchestrator/run.sh`, `codex.md` item 2), so a sandbox refusal becomes a reviewed escalation, not a stop.

## Amendment 2026-10-27: generator exception precedence (DIV-9.16)

The Maintainer ruled the one case item 10 could not match. When a loop body throws and the owned generator's `finally` also throws, the body's exception wins, as JavaScript's iterator close keeps it, not PHP's. This is recorded as DIV-9.16. The item's implementation already behaves this way, so it needs no re-derivation, only its review and full harness. It leaves epic 14's `waiting_on_maintainer` (#495).
